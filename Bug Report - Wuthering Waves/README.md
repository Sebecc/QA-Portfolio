#  Player character falls below the map after teleporting during gliding

## Summary

The issue was reproduced using Lynae. When the player teleports during gliding, the character falls below the map instead of remaining on the terrain.

## Environment

- Platform: PC
- Operating System: Windows 11
- Game Version: 3.2
- Reproducibility: 2/2 attempts as seen in the video

## Steps to reproduce

1. Open the game
2. Log in into the game
3. Choose Lynae as active character
4. Change character action to gliding
5. Teleport to waypoint seen in the video
6. Wait for the game to reload
7. See the result

## Expected result

Character Lynae should stand on terrain 

## Actual result

Character Lynae is gliding below the actual map

## Severity

Medium
